# brand/

Titi brand pack — read [`BRAND.md`](BRAND.md) for the rules.

| Path | What |
|---|---|
| `brand.json` | version, fonts, outputs, consumers |
| `tokens/` | DTCG 2025.10 tokens (generated by `scripts/tokens.mjs` from `scripts/palette.mjs` + `motion-spec.mjs`) |
| `contrast-pairs.json` | every shipped fg/bg pair (WCAG gate input) |
| `logo/` | symbol, optical sizes, wordmark, lockups, construction, animated SVGs |
| `fonts/` | Manrope + Geist Mono (OFL) static instances + WOFF2, licences |
| `icons/ios-liquid-glass/` | layer SVGs for Icon Composer |
| `templates/` | social, README header, A6 invite cards |
| `stickers/` | reaction stickers |
| `demo/motion.html` | live logo-motion demo |
| `concepts/` | gate evidence: concept sheet, palette sheet, brand sheet |
| `archive/v0/` | previous mark |
| `scripts/` | generators and gates |

```powershell
node brand/scripts/build.mjs                 # regenerate every output in the repo
node brand/scripts/build.mjs --check-text    # CI drift gate (text + vectors)
node brand/scripts/contrast-gate.mjs brand/contrast-pairs.json
<venv>\Scripts\python.exe brand/scripts/check-glyphs.py --union brand/fonts/Manrope-Variable.woff2 brand/fonts/GeistMono-Variable.woff2
# fonts/wordmark base (needs fonttools): python brand/scripts/extract-glyphs.py android/app/src/main/res/font/manrope.ttf android/app/src/main/res/font/geist_mono.ttf
```
