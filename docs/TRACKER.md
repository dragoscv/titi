`blocked(<reason>)` · `deferred(<version>)`. Every `done` must name its
evidence (test, command output, device). Update in the same commit as the
code. Reality check at the end walks every row.

Legend of surfaces: **C** core (Rust) · **B** backend · **A** Android ·
**W** web · **I** iOS · **D** docs/ops.
